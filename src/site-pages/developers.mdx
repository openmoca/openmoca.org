**Portable grounding for AI.** A MOCA package carries a work with its
structure, its original sources, its credits and the creator's terms, sealed
by one digest and optionally signed. A Reader opens it, verifies it, searches
it and cites every result the same way, in any language, on a server or
offline. Build a player, a reader, a search, a course or an AI assistant on
it.

## What you get

- **An open specification**: the package format, the Reader contract and
  interface, attestations, encrypted packages and sidecar indexes, under
  Apache-2.0 ([the specification](/spec/)).
- **@@release.readers@@**, in-process libraries that reach the same
  conclusions about every package ([Readers](/readers/typescript/)).
- **@@release.suite@@**: a package, options and the conclusions every Reader
  must reach, for each case ([conformance](/spec/conformance/)).
- **Tools** to convert, check, sign and index packages, and an MCP server
  for any AI assistant ([tools](/tools/)).

No permission needed: anyone can implement the standard. Software that passes
the suite for what it is may say it is [OpenMOCA Conformant](/conformant/).

## A package, in three layers

Build with what each layer gives you: content to search and cite, structure
to narrow and order results, evidence to check every quote against the
original, and the trust that runs through all three. A MOCA package wraps an
[Open Knowledge Format](https://github.com/GoogleCloudPlatform/open-knowledge-format)
bundle, a folder of Markdown with YAML frontmatter.

## Start in three steps

1. **Install a Reader**: `npm install @openmoca/moca-core`,
   `dotnet add package OpenMoca.Reader` or `pip install moca-reader`
   ([get started](/start/)).
2. **Open, verify and search a package**, and cite what you find with the
   citation record each result comes back as
   ([consuming packages](/docs/guides/consuming/)). Before you hand content to
   a model, ask the search to apply the creator's terms
   ([showing terms honestly](/docs/guides/showing-terms/)).
3. **Run the conformance corpus** against your Reader, or make a package of
   your own and check it ([quickstart](/docs/quickstart/)).
