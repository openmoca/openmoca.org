OpenMOCA is an open project. Most conversations happen in the open, on
GitHub, so everyone can see the answer.

| You want to… | Go to |
| --- | --- |
| Ask a question, or share an idea or a use case | [Discussions](https://github.com/openmoca/moca-spec/discussions) on moca-spec |
| Report a bug in the specification, a Reader or a tool | An [issue](https://github.com/openmoca/moca-spec/issues/new/choose) in the repository concerned |
| Propose a change to the specification | A [spec change proposal](https://github.com/openmoca/moca-spec/issues/new/choose); see [contributing](/project/contributing/) |
| Report a vulnerability | Privately, as the [security policy](/project/security/) says. Never in a public issue |
| Anything else: adopting MOCA, partnerships, press, licensing, using the OpenMOCA name | [hello@openmoca.org](mailto:hello@openmoca.org) |
